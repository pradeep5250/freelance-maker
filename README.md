# Freelance Maker

A modern, responsive web application for freelance creatives and service providers with zero commission.

## Tech Stack
- HTML5
- Tailwind CSS
- JavaScript

## Pages & Structure
- `index.html` - Main landing page with featured categories and services
- `categories/` - Directory pages for creative disciplines
- `services.html` - Service listings and features
- `membership.html` - Platform membership details
- `about.html` - Platform mission and background
- `contact.html` - Client and freelancer support inquiry form
- `terms.html` - Service terms and conditions

## Getting Started
Clone the repository and open `index.html` in any modern web browser or serve via:
```bash
python -m http.server 5500
```
